本表描述已交付代码和操作边界，不代表当前网络、账号或站点已实时验证。每次使用先运行 `jobs channels` / `jobs route`，以实际返回区分计划、执行失败、鉴权和结果；历史核验见 [CHANGELOG](../CHANGELOG.md)。

## 2026-11-07 方案核对与实际验证

核对 GitHub 源码与官方文档后，采用现有标准库核心加可选浏览器执行器，不整体引入第三方服务栈：

| 方案 | 核对结果 | 本项目采用方式 |
| --- | --- | --- |
| [猎聘官方 CLI](https://github.com/liepin-tech-2026/liepin-cil) / [官方授权页](https://www.liepin.com/mcp/auth) | 官方提供搜索、页码和筛选参数；页面列出 60 次/分钟共享额度。官方源码仍使用当前相同接口 | 借鉴公开请求契约，新增有界分页、重复页停止、部分失败保留；未复制上游源码 |
| [ZhaopinData](https://github.com/Wuliu4250/ZhaopinData) | Selenium，手动登录、页面翻页与 CSV；GPL-3.0。作者自述约 1000 条/4 小时，不是本项目实测 | 借鉴可见页面采集、分批保存与恢复思路，独立实现，不复制 GPL 代码或历史数据 |
| [job-crawler](https://github.com/silie666/job-crawler) | 宣称支持多家国内平台，但源码最后推送为 2024-04-24，未声明许可证 | 不作为当前可用性证据，不直接捆绑 |
| [JobSpy](https://github.com/speedyapply/JobSpy) | MIT、仍维护；列出的主要平台不含 Boss、智联、猎聘 | 不作为本轮国内渠道解决方案 |

本轮公开浏览器检查：智联显示验证页，Boss 返回加载页，猎聘页面未完成加载。已有授权的猎聘搜索返回 HTTP 302，未获得有效卡片；不推断为 Token 失效，也未发现官方接口迁移证据。专用交互浏览器启动被宿主自动审批阻止，因此登录态实测未完成。隔离虚构页面的真实 Edge 测试覆盖 DOM 读取、翻页和去重，不能替代真实站点验收。历史论文数据或开源 README 不能证明今天所有页面都能无登录访问。

运行时可通过 `career_settings` 中的来源注册表增加公开来源 URL、停用或恢复路线；停用状态会跨运行保留，启动批次时跳过停用路线。内置目录仍只是计划来源。多渠道流程先为每个启用路线取得至少一条实际尝试回执，随后最多两轮针对性修复，再做两轮不同扩词。等待登录/验证需要用户处理，但不会阻挡其他路线。公司目录、扩页、完整 JD 及经验方向均按独立阶段报告，不以计划或职位标题冒充已完成搜索/核验。

## 来源与开放状态

线索存 `search_leads`，取得真实完整单岗 JD 后才可提升为 `jobs`；精确 URL、发现/读取方式和时间不能补造。`has_more` 只说明首个公开结果页的解析数量超过请求数，不表示网站总分页数；扩大覆盖应改变检索条件，不能声称本地结果是全网全集。

保留官网 URL、聚合 URL、上游验证标签与本地读取时间；缓存命中不刷新来源日期。聚合站读取成功、官方搜索卡片或 fresh 均不能证明岗位仍开放。雇主官方单岗页面可提供雇主发布及投递入口证据，仍需核对该岗位本身的当前日期与状态；缺失则保持 unknown。

## 本地读取与停止条件

职页公开适配请求限时 15 秒、响应最多 2 MB、同进程间隔至少 2 秒、固定 HTTPS 主机、同主机重定向并检查 robots。多个 CLI 进程不共享限速锁，抓取命令顺序执行。官网读取只接受公共 HTTPS 域名、443 端口、无 URL 凭据，拒绝 IP 字面量与内网后缀，并有 robots、同主机重定向、15 秒及 2 MB 上限。

robots 无法读取、挑战页、非预期结构或无可读完整 JD 时停止并报告具体限制，不把失败记成零岗位，不绕过验证，不把列表页/摘要提升为岗位。第三方页面只作数据；任何上传、登录、联系或提交均遵循 [AGENTS](../AGENTS.md) 的人工边界。
